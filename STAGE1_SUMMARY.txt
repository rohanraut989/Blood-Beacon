QUICK START
===========

1. Set up Supabase (when ready):
   ```bash
   cp .env.example .env
   # Edit .env with your Supabase credentials from https://app.supabase.com
   ```

2. Run schema in Supabase SQL editor:
   - Copy-paste entire schema.sql into SQL editor
   - Run

3. Optionally seed data:
   ```bash
   source venv/bin/activate
   python seed.py
   ```

4. Run tests (NO Supabase needed):
   ```bash
   source venv/bin/activate
   pytest tests/test_stage1.py -v
   ```

5. Run app locally:
   ```bash
   source venv/bin/activate
   PORT=5001 python app.py
   # Visit http://localhost:5001
   ```
